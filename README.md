Senior software engineer and network administrator working primarily with **NixOS**, **Rust**, **Python**, and Linux infrastructure. I care about declarative environments, clear architecture, secure defaults, and software that can actually be deployed.

### [Lavis](https://github.com/zumuvik/lavis)

A Telegram userbot and external-module runtime written in Rust, built on MTProto with `grammers`.

- modular command architecture;
- external modules over JSON Lines;
- persistent aliases and configuration;
- Nix flake, CI, and NixOS integration.

### [Phonect](https://github.com/zumuvik/phonect)

Local Linux session unlocking from Android using biometric confirmation and signed challenge-response authentication.

- Android Keystore and `BiometricPrompt`;
- RSA-PSS challenge-response and TOFU pairing;
- local-network discovery without cloud services;
- packaged as a Nix flake and NixOS module.
